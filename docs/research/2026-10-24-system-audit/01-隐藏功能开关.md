# MagicOS 11 可解锁功能调研（2026-10-24，实测+社区知识）

方法：设备实测（getprop/settings 三表/device_config/pm features/su 只读 ls，零写入）；社区项标「待验证」。
基线：verifiedbootstate=green、flash.locked=1；荣耀特性 prop 前缀 msc.*（305 个）、persist.sys.iaware/hyperhold，由 feature_enabler_client 注入。settings put 免重启即生效可回退（/data 持久）；msc.*/persist.* 需 resetprop（会话层）。

## 显示与高刷
| 项 | 命令（先核对现值） | 效果 | 风险 | 价值 |
|---|---|---|---|---|
| SDR→HDR 视频增强 | settings put system hn_sdr2hdr_switch 1（现0） | SDR 视频提亮提对比 | 低 | 3 |
| SDR+ 画质 | settings put system hn_sdrplus_switch 1（现0） | 姊妹开关 | 低 | 3 |
| 天山色彩引擎手动档 | settings put system hn_tianshan_switch 1（现0） | 臻彩色彩管理 | 低 | 2 |
| 关自动降刷新率 | settings put system reduce_refresh_rate_enabled 0（现1） | 静止界面不降帧 | 低 | 3 |
| 关 EGL CPU 节流 | resetprop magic.config.enable_egl_cpu_throttle 0 + setprop debug.gui.syncMode.eglCpuTrottling.enable false（均开） | 动画跟手/掉帧↓，功耗略升 | 中 | 4（会话层） |
| 高刷策略档 | resetprop persist.sys.hn_screen_freq 3（现2，语义待验证） | 全局调刷策略 | 中 | 2 |
| 低电自动深色 | settings put system enable_low_power_dark_mode 1（现0） | 省电联动深色 | 低 | 2 |

## 音频
- 蓝牙无级音量：settings put system infinite_volume_music_bt_a2dp 1（现0；speaker=80 已启用）｜低｜3
- 双 A2DP 同连：resetprop persist.bt.max.a2dp.connections 3（现2）｜中｜2
- 音效基线已全开（sws_mode=3、LDAC/aptX-HD 在 a2dp_offload.cap），无需动作

## 游戏
- AI 游戏稳帧：settings put global ai_game_boost_state 1（现0，待验证是否被读）｜中｜3
- 游戏省电：settings put secure game_power_save_mode 0（现1）｜低｜2
- 游戏助手全家桶/风扇联动已开（msc.gameassist.features、magickey.game_boost_fan=1）

## 充电电池
- Turbo 快充常开：settings put system charge_turbo_switch 1（现0；support_charge_turbo_always_on=1）｜中（发热）｜3
- 自定义充电上限：settings put system UserBatteryLimitState 1（现0；battery_soc_control_feature=1）｜中｜3
- 内存扩展调参：resetprop persist.sys.hyperhold.swapsize 20（现16GB）｜高（伤闪存）｜2 不推荐
- 省电自动化：auto_quit_save_mode_enabled 1、open_night_mode_with_save_mode 1（均0）｜低｜2

## 网络
- 解锁「启用5G」开关：resetprop msc.settings.support_5g_mode true（现false 被屏蔽）｜中｜3（会话层）
- IMS 数据通道：settings put system show_ims_datachannel_switch 1（现0）｜低｜2
- 网络模式锁定：preferred_network_mode1 26（现69 全模；26=LTE 优先）｜中高（可断 5G/VoLTE）｜2
- 智能选网/网速：smart_network_switch 1、show_network_speed_enabled 1（均0）｜低｜2

## 观察项（不动）
hyperhold.permanently.closed=0、msc.window.hndesktopmode=8192（电脑模式位）、msc.super_device.capability_level 全开、msc.config.support_led=false（无硬件）

## Top5（价值/风险比）
1. 关 EGL CPU 节流（4/中，会话层）
2. SDR→HDR + SDR+ 双开（3/低，持久层）
3. 全屏 AOD（3/中）
4. 充电二件套：Turbo 或限充（3/中）
5. 找回「启用5G」开关（3/中，会话层）

通用：动手前先 getprop/settings get 记录原值；resetprop 项重启失效需固化（会话层限制）。
