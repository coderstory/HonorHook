## 2a. 非荣耀设备协同面（协议实证）
**投屏（PCAssistant = 投屏/PC 连接主力，非 Miracast-only）**：
- Miracast/WFD：内嵌高通 WFD 栈（com.qualcomm.wfd.*，RTSP SETUP /wfd audio/video、WFD R2、HDCP WFD_CONTENT_PROTECTION）→ **可对接任意标准 Miracast sink（含 Windows 无线显示器、通用电视）**。
- **乐播 LeLink SDK 实锤**：`POST /lelink-mirrormode RTSP/1.0`、`gslb.hpplay.cn/lebo-flux-sdk`、`test01-saas.hpplay.cn` → 与乐播投屏生态互通（海量非荣耀电视/盒子）。
- DLNA/UPnP（含 `upnp-api.vivo.com.cn` 联盟 API）、HiSight（荣耀自研 mirror 协议，DEVICE_TYPE 映射）。
- 结论：**投层面非荣耀设备互通性高**（Miracast+乐播+DLNA 三通道）。
**连 Windows**：pcassistant（WFD 投屏 + INcDft 文件传输框架 + softnet NearStrategy P2P）+ **microsoftsdk.crossdeviceservicebroker（微软 Cross-Device/Phone Link broker，声明 READ_CLIPBOARD_IN_BACKGROUND + MANAGE_MEDIA_PROJECTION）** → Windows 互通走微软 CDP 通道 + 荣耀自研 NcDft，**非荣耀 Windows PC 可用**（Phone Link 是微软标准协议）。
**连接发现/文件**：nearby = 自研 softnet（BLE 扫描 + WiFi P2P 5G DFile 文件传输，TLS ECDHE_RSA/ECDH）；iConnect config.json 云控设备目录 150 项：90×CAR(HiCar)、键盘 15、PEN 9、TWS 8、PC 4（MateBook/MagicBook/NoteBook/通用PC）、PAD 1…… **含华为遗留设备（FreeBuds/MatePad Keyboard/M-Pencil）→ 荣耀-华为外设互通仍在**；**无任何通用 Android 手机/平板目录项**。

## 2c. 跨设备剪贴板/拖拽/流转
- 剪贴板：handoff 内 ClipboardManager + `sendCopyEventByMagicLinkBroadcast`（MagicLink 通道广播复制事件）；CDSS 也有 clipboard 引用 + ClipBoard。跨设备粘贴走 handoff 的 **MagicLink**（本地）或 **hwddmp cloudlink（cloud.hihonorcloud.com 云推送，跨接续走云）**。非荣耀设备：MagicLink/cloudlink 均需对端荣耀协议栈 → **不可用**（Phone Link broker 的剪贴板仅限 Windows+微软通道）。
- 文件拖拽：CDSS 完整 drag&drop 框架（UeDragFileInsertEntry/drag out/Transfer Center）+ nearby DFile P2P；OneHop 一碰传=emcom onehop_certificate 白名单应用专属。
- 应用流转（接续）：handoff 双向（sink/src），错误码 ERROR_SINK_PKG_NOT_ALLOWED_START / SINK_HANDOVER_VERSION_UNSUPPORT；**checkSinkAppAuth 按 handoff_certificate_china.json 白名单**。
- 虚拟摄像头：CDSS 含 VIRTUAL_CAMERA_STREAM（PC 等对端可把手机当摄像头）。

## 3. 协同能力地图
**生态内（荣耀/华为）**：多屏协同（手机↔MateBook/MagicBook 三窗口、PC 控制手机+通话）、pad 协同、应用接续（6 白名单应用）、跨设备剪贴板、文件拖拽/DFile P2P、虚拟摄像头、HiCar、一碰传（18 白名单）、通知/通话共享。
**生态外可用**：Miracast 标准投屏、乐播生态投屏、DLNA、Windows Phone Link（微软 broker，含后台剪贴板/投屏授权）、USB 网络共享。
**生态外不可用**：多屏协同全套、接续、跨设备剪贴板（荣耀通道）、nearby 文件（需 trustcircle+平台签名）、闪连 linktime（已冻）。
