# 融合状态栏 v1.4 实现规格书（2026-10-24，全部签名 dex 实证）

宿主=systemui-magicos11.apk(SU)；竞品=honorduo.apk 1.0.2(HD)。所有类#方法#字段经 dexq 逐字验证存在。

## 1. 锚点全签名（9 个）
1.1 `statusbar.phone.ui.StatusBarIconControllerImpl#setIconVisibility(String slot, boolean visibility)`→void。**before**：slot∈D 常量表(wifi/mobile/…+demo_*) 且 visibility==true 时改参为 false 放行；系统主动隐藏直接放行。辅锚 `onTuningChanged(String,String)` after 重放黑名单（tunable 重置可见性）；有 `setDefaultIconBlackList()`、字段 `mIconBlacklist:ArraySet`。勿用 removeAllIconsForSlot（破坏性）。
1.2 `HwStatusbarContents`(ViewGroup, xml 根)：`onFinishInflate()`/`onAttachedToWindow()` after：findViewById 抓容器并 addView 注入自绘胶囊（双时机兜底 inflate 顺序）。`onDarkChanged(Rect,float darkIntensity,int iconTint)` after 同步 tint；`onKeyguardDarkChanged(int)` 锁屏暗色链独立存在。字段实证：mSystemIconArea:HwSystemIcons、mColoredCapsuleParent:LinearLayout、mClockArea、mSignalIcons、mCapsuleLeft/Right:int、mHasCapsuleShown/mHasColoredCapsuleShown:boolean。
1.3 `battery.HwStatusBarBatteryView`：构造(Context,AttributeSet,int,int)四参齐全；刷新=`onBatteryUpdate()` void。可反射读：mLevel:int、mIsCharging/mIsPlugged/mIsPowerSave:boolean、mInsideLevelView:BatteryTintView、mInsidePercentView:HwTextView、mTintColor:int、mCriticalBatteryLevel:int。挂点=onBatteryUpdate after 广播 State；构造 after 存 WeakRef。
1.4 `phone.HnPhoneStatusBarAnimController`（单例 getInstance()）：避让字段组**只读反射不 hook**（抄 HD）：mIsStatusBarScaleDown/mIsCollapsedCapsule:boolean、mCapsuleExpandState:int、mIconAvoidSwitchOff:boolean、mColoredCapsulePadding:int、mHasAndShowCapsule:boolean。读取时机=每次胶囊定位前；方法备查 updateCapsuleState(int)/setContentsVisibility(boolean)/startStatusBarAnim(boolean,boolean,boolean)——若 hook 只 after 观测。
1.5 VM：`pipeline.mobile.ui.viewmodel.HnMobileIconViewModel`——全 ReadonlyStateFlow 字段：isVisible/icon/mobileStrengthId/mobileTypeMasterId/mobileTypeRoamId/networkTypeIcon/networkTypeBackground/roaming/activityInVisible/activityOutVisible/activityContainerVisible/showNetworkTypeIcon/showBusyIcon/contentDescription，`subscriptionId:int` 双卡区分。`HnWifiViewModel`——hnWifiIcon:ReadonlyStateFlow<Int>(res id)、isNoInternetViewShow/isWifiCharged/wifiInOutState。**VM 实例获取**：SystemUI 用 Dagger，从注入 View 拿不到→降级走广播自采（§4）。
1.6 暗色：`DarkIconDispatcherImpl#applyDark(DarkReceiver)/addDarkReceiver(ImageView)/setIconsDarkArea(Rect)`、字段 mIconTint:int/mDarkIntensity:float/mDarkChangeFlow。胶囊 View 实现 `plugins.DarkIconDispatcher$DarkReceiver#onDarkChanged(Rect,int)` 并注册。
1.7 装配：`HwStatusBarIconController$NotchDarkIconManager`——mStatusIcons/mStatusIconsMore/mNetworkAreaIcons/mNetworkAreaIconsMore:LinearLayout[4]；`getIconViewFromGroup(String,ViewGroup):StatusBarIconView` 可反射；onIconAdded(int,String,boolean,StatusBarIconHolder) 每 icon 落位总口（最细隐藏粒度）。

## 2. 隐藏策略定稿=混合
- 控制器层 setIconVisibility intercept（主 slot）→ 锁屏/通知头多 IconManager 实例自动联动；onTuningChanged after 补写
- View 层兜底 suppression ticker（500ms 观测 mSystemIconArea 子 view，tag/slot 命中且非我们胶囊→GONE），周期由 ScreenState.isScreenOn 门控（HD 实证 StatusBarIconManager#enforceSuppression/hide/rememberHidden/restoreSlotIcon 同思想）

## 3. 注入序列
首选容器=`mColoredCapsuleParent`（彩色胶囊官方容器，避让系统已为其算 padding：`HwSystemIcons#setColoredCapsuleArea(int,int,boolean)`、mCapsuleAndStatusIconSafeDistance/mBoundaryLeft/Right 语义=状态图标区左右安全边界+最小间距）。次选 mSystemIconArea（需自算 padding=mBoundaryRight+SafeDistance）。addView 至 index 0，系统避让动画（HnStatusBarIconAvoidColoredCapsuleController）自动把它当彩色胶囊处理（updateIconVisibilityForColoredCapsule 同源）。

## 4. 数据绑定表
信号：mobileStrengthId StateFlow<Int>(0..4 档点阵)/roaming/subscriptionId/activityInOut；降级=TelephonyManager(HD TrioState$Companion.startDataActivityListener 同款)。WiFi：hnWifiIcon(res id→level)；降级=WifiManager/RSSI。电池：粘性广播或反射 mLevel/mIsCharging/mCriticalBatteryLevel。时间：自绘 Chronometer（HD ClockTicker 每分钟 handler）。深浅色：DarkReceiver tintArea 空=全域，iconTint 即目标色。

## 5. 自绘胶囊
高=状态栏高；tint 优先 onDarkChanged iconTint，区域混色抄 applyDark rect 相交判定；胶囊底=iconTint 12% alpha（HD withAlpha/lighten 实证）。圆环电池：HD TrioAppearance$Ring 参数面（dual/bolt/parts:int[]/arcStart/sweep/gapStart/gapEnd）作配置 schema；strokeW=状态栏高*0.06、sweep=level%*300°、gap 底部 60°。防烧屏=Row.burnInTask 周期微移±1px；熄屏停动画=ScreenStateTracker(isScreenOn/addListener/start(Context) 全实证)。**绘制内核直接抄 HD TrioRenderer#drawFreeRing+drawCapsuleDots 两条静态方法**。

## 6. 失败模式与 PROTECTIVE
降级矩阵：setIconVisibility 缺→仅 View suppression（独立成立）；HwStatusbarContents 缺→不注入报 PARTIAL；VM 缺→广播自采；BatteryView 缺→纯广播；AnimController 字段缺→手算避让；DarkIconDispatcher 缺→uiMode 自判。
崩溃回退：全 hook try/catch+单锚点熔断（连续 3 异常 unhook+log）；四独立开关（胶囊总/隐藏原图标/自绘信号/自绘电池）。
共存：检测 io.github.odomu.honorduo 已压制同 slot（读子 view visibility）则跳过；药师 blur 域无交集。
