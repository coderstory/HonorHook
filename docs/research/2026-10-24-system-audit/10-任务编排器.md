## 触发与编排（关键实测）
- **root 在场判据**：app uid 下 /proc/modules、/data/adb、/proc/version 全 SELinux denied；唯一可靠 = spawn `su -c id` 试探（检测本身花一次 su 调用）；su 文件 stat 存在性作佐证
- 无「su 可用」广播：前台服务低频轮询（30-60s）+ 免轮询增强（开屏/解锁即测 + BOOT_COMPLETED 一次）。检测到→通知「root 在场，N 项待办」，点击确认页，**不自动执行**
- 常驻性：iaware 在场 → 前台服务仅「开机后 30 分钟窗口」轮询，之后停；降级形态=打开 app 即检测
- 持久化：queue.json + history/<ts>.jsonl（动作id/exit/回读值/错误），app 私有目录 root 失效仍可读
- 幂等：settings put / pm disable 幂等；每动作独立事务（pending→done），中断续跑

## 与一键越狱边界（产品原则）
只探测（pm list 免 root 可确认 com.dsh.aakan00）不调起：①自动触发=自动执行内核漏洞利用（DIRTY/panic 风险+烧 24 次开机预算）责任不可负；②灰色合规；③提权是用户仪式感操作。增强：工具在装+root 不在→双步骤引导文案。

## 免 root 能力（实测校准）
- settings CLI app 不可用，但 **Settings.Global/Secure API 大部分键可读** → 每周哨兵自查完全免 root（WorkManager）
- ACTION_BATTERY_CHANGED 粘性广播可收（level/voltage/temp 粗粒度）；SOH/循环数精确值必须趁 root
- getprop 部分键 untrusted 空 → 固件指纹用 Build 字段兜底

## 风险与减法
①冻结错包=brick 级：禁碰白名单外置+执行前逐包校验；②批量确认：逐项勾选+执行摘要+中风险类二次勾选；③中断：事务化+幂等续跑；④云回写：A6 复查提示；⑤会话/持久层心智隔离：UI 分区。
MVP 砍掉：A4/A8/A9、自动提权、常驻默认开、历史曲线图表（先攒数据）。
