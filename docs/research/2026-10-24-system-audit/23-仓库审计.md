# HonorHook 全库实现级审计（2026-10-24，~100 kt 全读）

## 一、核心引擎能力表
**HookEntry**：onPackageLoaded→TargetRegistry.find(pkg)→RemoteConfig.attach（一次 Binder 读）→逐 target install，per-target runCatching 隔离。新目标三件套=注册表一行+scope.list 一行+FeatureCatalog 一项。
**TargetRegistry**：33 个 TargetHook（20 包）静态注册；对象级防重装；find 未注册返回空静默。
**MountEngine/Session/Outcome/Scheduler**：
- open(hookName,hostPackage,apkPath,expectedHostVersion,gate) 会话工厂，构造期定参（杜绝旧两阶段忘 begin）
- Task 协议：id/className/methodName/paramCount/returnType/description + group/feature/dex(DexHint)/resolveValue；SimpleTask 零逻辑复用
- 失败分级：FAILED=挂载异常；NOT_RESOLVED=未就绪重试（≤2 轮 500ms/2000ms）；MERGED=同方法同功能计成功不扣 N；MERGED_CONFLICT=合并到别功能计失败
- installed N/M：首轮记 M（重试不覆盖）；N=OK+MERGED；全灭 group 升 ERROR；口径由 MountSummaryTest 钉死（JVM 可回归）
- PROTECTIVE：module.hook(method).setExceptionMode(PROTECTIVE)+intercept(watched)；框架吞异常回退原调用，模块 wrap 记 WARN(≤3/task) 后原样 rethrow
- 主线程不变量：install 在主线程，attemptMount 首轮转投 MountScheduler 后台执行，零同步磁盘 IO；版本自检延后 1s（不一致 WARN 不阻断）
- 日志节流：判据 2/任务、回调异常 3、漂移 1；汇总行永输出

**MethodResolver(408行)+DexKitHelper+DexQueryPlan+DexHitSelector（混淆对抗）**：
- 三阶段：①直连反射（不缓存赌类后加载；paramTypes 序列消重载+int/Integer 归一）②严格轨（名/签名钉死+包名白名单）③宽松轨（只用内容锚点，名/签名降级打分：类名1000>方法名100>paramTypes 每位10>paramCount5；唯一胜出才采纳，并列=Ambiguous 不猜）
- 宽松三层：L1 方法体串 / L2 类锚+方法体串+声明类硬约束 / L3 类级（classStrings+classFieldTypes）
- DexHint 四维锚点：方法体字符串/参数类型序列/类内字符串/类字段类型 + instanceOnly（防 thisObject 空转）；abstract/native 不可挂，static 可挂
- 安全阀：默认包类无锚点不裸扫；严格轨唯一候选无锚不采纳；候选集不完整不做唯一判定、null≠空命中
- 缓存三桶按 ClassLoader 分桶；同方法跨点 Claim 原子占位（putIfAbsent）
- **未用潜力**：DexKit 调用链查找（callers/callees）、字段查找、字符串批量反查均未接入（现只有 findMethod）；纯逻辑无字符串方法仍无锚

**FeatureGate+HostVersion**：pick 三级=精确套→默认套(空版本集)→fallback 选最大版本号套盲挂（installer 显式 opt-in）；版本双取法零隐藏 API。版本表注册=InstallerHook.installerTables 模式（版本集唯一来源 FeatureCatalog.extraVersionsOf，空集守卫）。
**开关体系**：UI 侧 FeatureStore 本地 prefs+远端 prefs 双写互斥；hook 侧 RemoteConfig 只读注入读不到回目录默认（默认全开 4 例外关）；延迟一轮生效；重装 pushAllToRemote 对齐。FeatureCatalog=KEY_* 唯一事实源（275 行，~50 key/18 Target）。数据表=Entry/Rule 列表+命中短路/未命中放行，DecisionTablesTest 钉契约。

## 二、hook 模式五式（target/*.kt 提炼）
| 式 | 代表 | 判据 |
|---|---|---|
| P1 值替换(before 不 proceed) | installer addConst、CloudSwitchTable.forced | 布尔/数据源读点，宿主自带关闭分支 |
| P2 not-proceed(空短路) | JdHook Splash 永不挂载、installer AB 请求 | void 方法、消费点唯一、宿主走无数据路径 |
| P3 after 语义(改参/改返回) | updateSubs 过滤 proceedWith、ThemeStore VIP 填值、StatusBarIcon 换 Drawable | 需原逻辑先跑再外科手术；**void 回调显式 return null**（SystemUiHook.kt:283-285 崩溃实证） |
| P4 响应出口清理 | AdSlotFilter 按 slot 删、BottomTabFilter 裁后<3 项整体放弃（防宿主回退静态分支） | 服务端列表裁剪，守住回退阈值 |
| P5 视图注入/框架收口 | DualSignalFeature onAttachedToWindow 注入、MfaAuth 360 加固挂 Activity.onCreate | 加固/时序赌不赢业务类；UI 无法数据 hook 表达 |

建模：改数据/开关→P1；砍入口→P2；需原逻辑→P3；列表裁剪→P4；画 UI→P5。

## 三、app 面
MainActivity 249 行三 Tab；AppSettings 直订阅；悬浮底栏与内容层必须兄弟节点（防 backdrop 自采样 SIGSEGV）。**su 通道=ScopeCommand+ScopeRestarter**：su 候选 4 路径探测缓存；ps 解析 Map<pkg,Set<pid>>；kill=kill -9 pidof 在前+am force-stop 在后（persistent 进程 force-stop 无效）；Runtime.exec(su,-c,cmd)、5s 超时 destroyForcibly、独立线程读 stdout 防假超时、失败三态 NO_SU/NOT_GRANTED/TIMEOUT、包名白名单防注入。**边界：无交互式命令/stdin/quoting 策略、超时硬 5s、stderr 不采集、无 root 文件读写 API**。更新链：GitHub releases+5 镜像赛马下载。持久化全 SharedPreferences（无 DataStore）。

## 四、技术债
1. void 回调隐式返回崩溃案（已全库修复留注释，新 hook 必须沿用显式 return null）
2. 挂载点声明四格式并存（表/源码 addConst/字符串模板/SDK 内联），~14 目标未表化
3. scope.list↔Registry↔Catalog 三方一致性靠人：calendar/browser/quickgame/youku/cloudmusic 5 个 SDK 通杀包 Catalog 无 Target（key 挂 totemweather 卡下）
4. MountTask 私有类重复构建器（SimpleTask 替代未完成迁移）
5. baselineVersionOf 落空=版本自检静默关

## 五、三新功能落点（文件级）
