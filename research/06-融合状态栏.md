# 融合状态栏（iPhone Duo 样式）调研（2026-10-24）

方法：自写只读 dex 解析器 $HOME/dexq.py（MT MCP 宕机自救）+ aapt2 xmltree + curl web。

## 视觉规格（iPhone Duo，2026-09-09 发布）
状态栏收右上角一簇：时间+WiFi+蜂窝（蜂窝改圆点）；电池呈圆环/胶囊 battery circle；胶囊独立底色（深色半透明/浅色浅灰），tint 跟随系统。目标样式=右侧单一胶囊簇：信号点阵+WiFi+圆环电池。

## 类面锚点（全部实测，APK=system-files/systemui-magicos11.apk）
- 隐藏原图标最稳点：`StatusBarIconControllerImpl.setIconVisibility(String,boolean)` + `onTuningChanged(icon_blacklist)` tunable 兜底；本 build 无 setExternalIcon
- 容器装配器：`HwStatusBarIconController$NotchDarkIconManager`（4 个 LinearLayout：statusIcons/mStatusIconsMore/mNetworkAreaIcons/mNetworkAreaIconsMore；static getIconViewFromGroup）
- **头号干扰源**：`HnPhoneStatusBarAnimController.updateCapsuleState/setContentsVisibility`（胶囊避让动画总管，必须协同 hook）
- 电池=经典 View（HwStatusBarBatteryView，无 pipeline VM），数据走 ACTION_BATTERY_CHANGED 粘性广播
- 荣耀自带胶囊视图栈：`ColoredCapsuleStatusBarHelper`+`StatusBarColorCapsuleView`+`HnStatusCapsuleSet`（材质/动画可抄）
- pipeline VM 数据面齐全未混淆：HnMobileIconViewModel（icon/isVisible/mobileStrengthId/roaming/activityInOut 等 StateFlow）、HnWifiViewModel（hnWifiIcon/isNetworkConnected）
- slot 字面量：wifi/mobile/battery/airplane/bluetooth/zen/volume/hotspot/location/headset/ethernet/cast/recording/screen_record/rotate（+demo_* 演示槽须同步）
- 布局链（xmltree 实证）：hn_status_bar_contents → [colorring_start｜operator_name｜colored_capsule_parent｜clock｜system_icon_unstable｜system_icon_area(statusIcons→network_area_icons→signalIcons→battery)｜colorring_end]，右侧四段式
- uikit.hnfloatingcapsule 是悬浮窗灵动胶囊（非状态栏内），样式可抄实例不可复用

## 先例
HyperCeiler（5563★）statusbar 30+ 规则无真融合；其 StatusBarIconList 工厂挂法（ProvideStatusBarIconListFactory.provideStatusBarIconList）与本 SystemUI 同名同类可直接抄。结论：融合渲染需自研，开源无货。

## 方案
- **A（推荐骨架）**：setIconVisibility+VM isVisible 双保险隐藏原图标；运行时按 id 找容器 addView 自绘胶囊（圆点信号+WiFi+圆环电池，抄 StatusBarColorCapsuleView 材质）；协同挂 HnPhoneStatusBarAnimController；电池走广播。崩溃面中，工作量 M–L
- B（数据层融合）：VM StateFlow 聚合渲染，视图面改动最小，L
- C（过渡 demo）：复用 U7 三挂点轨把 drawable 换伪融合贴图，S（1 天出视觉效果，非真融合）
工程纪律：slot 名 D常量表+运行时 getSlotName 校验；demo_* 槽同步；锁屏/通知头 cluster 同源联动（隐藏会联动）写进验证判据；PROTECTIVE 兜底。
