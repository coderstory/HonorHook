## 1. RootShell（ui/scope/RootShell.kt，从 ScopeRestarter 提取）
保留全部语义（su 4 路径懒探测/5s 超时 destroyForcibly/独立线程读 stdout/三态 NO_SU·NOT_GRANTED·TIMEOUT）+ 新增 stderr 采集：
```kotlin
object RootShell {
  sealed interface Result { Ok(stdout); Failed(exit,stdout,stderr); Unavailable; Timeout }
  fun exec(command: String, timeoutSeconds: Long = 5): Result  // 批量 pm 链可传 15s
  fun probe(): ProbeResult   // F3 活性探测

```
单发决策：不用持久 su 会话（无 su 可用广播+iaware 杀常驻；spawn su -c 与现有一致）。安全：RootShell.exec 只内部用；对外 SafeCommands 工厂三枚（pmDisable/pmEnable/settingsPut/settingsGet/snapshotScript），pkg=PACKAGE_NAME 正则复用 ScopeCommand.kt:16；table∈枚举；key=^[a-zA-Z0-9._]+$；value 白名单（数字/布尔/null/限定字符串，拒引号分号换行）。

## 7. 风险
①批量冻结不做整批回滚：强制快照+失败不中断+失败清单；A 档 enqueue 前硬拦截 ②表陷阱：写错表=exit 0 静默无效——Entry 强制 table+回读验证；营销 11 键未核实表前标「待核实」③类型：回读字符串等值比对 ④KSU 授权弹窗时机：进页主动 probe 一次（用户在场点授权）⑤中途 root 失效：队列停 pending 提示续跑 ⑥云回写：cloudRewrite+隔天复查，不承诺永久。
