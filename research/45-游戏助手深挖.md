# 游戏助手深挖（2026-10-24，gameassistant 40.7MB + kitserver 线索）

样本：system-files/gameassistant.apk + ga/ 解包件 + ga_strings.txt（179k 行）。字符串层分析（无 jadx），未到 smali 级——frameList JSON 字段级待补。

## 帧率链（核心结论）
1) 数据源=**云端+本地缓存混合**：gamemanager 云 API（/gamemanager/api/v1/frame/*、/allow_list、/blocklist）按 pkg 下发 frameList JSON → Room 表 FrameInfoEntity 缓存；部分游戏（原神/星铁）由游戏侧 SDK 上报 I_TargetFrame（gsskeytrans/starrailkeytrans.xml TGPA 键）
2) 执行链：gameassistant(openFrameRate) → IGameService binder → kitserver setFpsLimit → **hnaps IApsService（系统 APS 真正限帧者）+ GueService SuperFrame（超帧/插帧）**；V2 档还需 isCloudSupportV2 云开关
3) **本地扩展判定**：改本地 DB 只解锁 UI 档位；实帧被 APS 侧 GameWhiteList 拦（"is not in GameWhiteList"），且云同步 12h/版本校验会覆盖 → **纯改本地表=大概率只改 UI，中高风险**
4) 稳妥路径=hook 指令流（下方 P1/P3），非改白名单

## 功能面
- 性能档：平衡/性能/超竞（PerformanceService+setGameMode+UniPerfEx uniPerfEvent+PowerKitService Sink 5x/6x）
- 画质：GraphicsEnhanceV2→GueService 超帧+独显增强（超分模型在 gamesr 包+GueService，本 APK 不含）

- 服务族：NotDisturbV2/AntiTouchV2/TouchEnhanceV2/Vibration4D/WifiEnhance/GameKeepAlive/MultiWindowApp(小窗)/RecallService(闪回，云端 blocklist)
- 极客中心=入口壳（msc.game.geek_center_enable+GeekMainActivityAlias），实现在 geekcenter/GueService

## Hook 阶梯（推荐顺序）
P1 ⭐ gameassistant 进程 IGameService.setData/getData（binder 指令流单点，改回包扩档，LSPosed 常规）→ P2 GaDataBaseHelper.insert/queryFrameList（本地注入+验证 APS 放行）→ P3 kitserver setFpsLimit 调用点（绕 UI 白名单直接下发）→ P4 hnaps IApsService$Stub（系统级，高风险备选）→ P5 GueService SuperFrame IsSupport 返回改写（给不支持游戏强开插帧，效果随画质）
