# 竞品对照：药师 HonorAdvancedSettings v1.4.22 vs Re:荣耀（2026-10-24）

样本：io.github.voreulch.honoradvanced v1.4.22(45)，system-files/honoradvanced.apk（705KB 单 dex）。经典 Xposed API（非 libxposed）；CfgProvider 配置走 ContentProvider 绕 SELinux；无 DexKit 无原生库，靠方法名+参数类型锚+三套版本分发（与我方 versionTables 同构）。

## 药师功能全表（摘要）
- 液态玻璃全家桶（systemui/launcher/photos/desktop.systemui）：机型档位强制 HIGH、FROSTED→LIQUID 翻转、blur 参数、锁屏壁纸位图合成管线（最深）
- 安装器净化 8 子项（跳安全检测/广告卡隐藏/Socket 禁网/跳指纹/staging）+ 安装包信息卡（视图注入）+ 允许降级安装（system_server scope）
- 诊断体系：persist.sys.lgr.kdiag sysprop 门 + logMiss 计数

## 对照判定
- **packageinstaller 重叠（高危）**：双方同 hook RbiTempBean/CardTipsRecord/PackageInstallerActivity —— 同装冲突根源
- systemui：锚点零重叠（我方状态栏图标域 vs 它玻璃域），但同进程诊断互相污染
- launcher：零重叠，keep_folder_open 与其 folder optics 语义相邻需回归
- 我方独有 17 包域（主题/设置/ouc/mms/ime/xhs/jd/健康/天气/壁纸…）药师完全不碰

## 收编候选（我方空白）
1. 机型档位强制 HIGH + FROSTED→LIQUID 玻璃解锁（纯值替换浅挂点）
2. 安装包信息卡（tv_card_* 资源 id 稳定，直接抄锚）
3. Socket 构造器禁网（粗粒度一刀切，比逐 SDK 稳）
4. 跳过指纹验证 hookFingerprintAuth
5. sysprop 诊断门 + logMiss 计数（补强 NOT_RESOLVED 粒度）
6. 降级安装（android scope + 重启，backlog，冲突我方禁 reboot 铁律）

## 冲突避让
① packageinstaller 不新增与药师同语义点；新功能先做「检测药师已装→提示二选一」（包名探测免 root）；回调 null-safe 容忍他人置空
② systemui 玻璃域整体让渡（uikit.transparency/magic.blur/壁纸位图管线不碰）；状态栏图标域为我方领地
③ launcher folder optics 与 keep_folder_open 共存回归后再并开
