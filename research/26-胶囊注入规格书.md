# 灵动胶囊注入规格书 v1.4（2026-10-24，签名级 dex 实证）

## 1. 路线定稿：主=C（通知通道，可零 hook），备=A（SystemUI 内直调），B 禁用
- **C 路（主）**：SystemUI 侧 `GlobalDynamicCoordinator$…onEntryAdded` 执行 `NotificationEx.getHnParcelable(sbn,"smart_island_capsule_data")`→CapsuleData→`processCapsuleData`→CapsuleManager#onDynamicCapsuleDataAdd。**此路径无签名/权限校验**（只有用户开关判 isAllowShowCardByUserSwitch）。喂法=普通 app：Notification + 反射 `Notification#setHnExtrasParcelable(String,Parcelable)`（fm dex 实证，hidden API→LSPosed 兜底 hook 该方法）。宿主无需 hook，零崩溃面。
- **A 路（备）**：SystemUI 进程内 `CapsuleManager#getCapsuleManager(Context)` 单例→自拼 15 参直调 onDynamicCapsuleDataAdd；hook DynamicManagerEx#addDynamicInfoListener after 存实例（P3 式）。崩=SystemUI 软重启，中风险。
- **B 路（禁用）**：服务端在**独立 persistent 进程 com.hihonor.systemserver**（sharedUserId=android.uid.system，非 system_server 主进程）。校验点=`InteractionDisplayService#isIllegalCalling`（getCallingUid+checkCallingOrSelfPermission(signature)+userId==0）20+ 入口全走它。技术可绕（hook isIllegalCalling 返 false）但崩该进程≈半砖（watchdog 视同系统进程），禁用。

## 2. CapsuleData 构造配方
- 模板 String 常量（11+default）：image_text/text_image(自动归一为 image_text)/image_image/image_text_text/image_text_text_image/image_text_image_text/text_text_image/text_text/**image_timer/image_text_timer/wave_timer**(wave 特判独立时序)
- 字段：mMainText/mSubText:CharSequence、mMainContent[]/mSubContent[]:String、mIcon(String,String)/mFirstIcon:Icon、mBrandColor/mCustomBrandColor:int、mStatusBarTemplate、mMain/SubContentRemoteViews、mSessionId/mUid、mExtraData{mStatusBarData,mAodData}
- capsuleType TYPE_*：DEFAULT=0/BUSINESS_DYNAMIC=1/SYSTEM_DYNAMIC=2/SCENE_CONTROL=3/IMMEDIATELY_FEEDBACK=4/MOMENT_FEEDBACK=5/INSTANT_FEEDBACK=6；通知路径映射 isPromotedOngoing()?3:1
- DynamicCardShowFlag：IMMERSIVE=1/DISABLE_KEYGUARD=2/FORCE_IN_APP=4/NO_DISTURB=8
- **degreeLevel：SystemUI 缺省填 23**（服务端 EEM 查表非法返 -3；C/A 路绕过服务端不受限，注入侧固定用 23）
- displayDuration:long（超时 REMOVE_REASON_DISPLAY_TIMEOUT=2）；setChronometer(isCountDown,startTime) 编码 "+/-"前缀字符串，基准=elapsedRealtime
- Bundle 键：**smart_island_capsule_data**（C 路核心）；capsule_anim/anim_level/dynamic_capusle_anim(原拼写)/anim_systemui_feature=私有动画键；capsuleData/capsuleColor/capsuleType=sendCustomData/JsCard 链（次要）
- 结果码：OK=0/NO_SERVICE=-1/ILLEGAL_ARGUMENT=-2/ILLEGAL_DEGREE_LEVEL=-3/CREATE_CARD_FAILED=-4/TRANSACTION=-5；INTERACTION_VERSION=8

## 3. 四场景最小实现（统一壳：CapsuleData→setStatusBarTemplate→setText/Content→setFirstIcon→setBrandColor→ExtraData(capsuleType+degreeLevel 23)→setHnExtrasParcelable→post ongoing 通知；更新同 key 重发、撤=cancel）
1) 计时器：image_text_timer + setChronometer(true, elapsedRealtime+剩余ms)；CapsuleCountDownTimerManager/CapsuleTimeRecord 接管 tick，到 0 自移除
2) 音乐：**标准 MediaStyle 通知即自动触发**（HnMediaDynamicControllerImpl#updateCapsuleData→MediaCard+musicSongInfo+封面旋转）——不手搓；仅自定义歌词动效才 C 路覆盖
3) 充电：电池/电源广播自采（22 号§4 同款）；低电 image_text 红色、超级充 wave_timer
4) 通知摘要：C 路本体，key=sbn key 天然防重

## 4. 避让与共存
调度三容器：mCurrentCapsuleRecords(ConcurrentLinkedDeque)/mDelayed(LinkedHashMap)/mInstantFeedback(插队)；选择口 getForgroundCapsule；**同 key 重复 Add 直接覆盖 map→多胶囊必须唯一 key**。与 HonorDuo 同域：检测其已注 MediaCard/同 key 冲突时让位（读 mCapsuleDataMap size）；mCurrentConflictCapsuleRecord 冲突展示逻辑存在。驻留 mDisplayTime/mExtremeDisplayTime（hook=无限驻留，S 级可选）。

## 5. 失败模式
C 失败（hidden API 拦/通知禁）→降 A；A 失败（混淆漂移）→PARTIAL 停用。判据=MethodResolver 严格轨锚 onDynamicCapsuleDataAdd 名+paramTypes 第 4 位 CapsuleData。void 回调显式 return null。**B 路写面 hook 禁用**（persistent 进程重启循环≈半砖）。

## 6. 测试矩阵
判据：`host=com.android.systemui (C兜底0-A备1/1)`。验收：①计时器倒数+到 0 自移除 ②MediaStyle→MediaCard 旋转 ③充电 5s 内现/拔即撤 ④3 条并发不同 key、foregroundChanged 不闪烁。回归：dumpsys interaction_display；连发 100 次更新 mCapsuleRecordMap 无泄漏。
