# MagicOS 11 系统 UI 可定制面调研（2026-10-24）

方法：root 只读实测 + 设备侧 curl（GitHub 可达/酷安不可达）。原始完整版：/storage/emulated/0/project/HonorHook-system-ui-customization-report.md

## 关键实测
1. **开机动画是 MP4**：/product_h/etc/media/bootanim.mp4 + vbootanim.conf（VIDEO_PLAY_SUPPORT=1, LOOP_START_TIME=10100, MANDATORY_PLAYING_TIME=12000）+ bootanimation.zip 兜底；libbootanimation_preapex.so 查找序含 /data/cust/media/bootanimation.zip 优先位。/product_h 不在 KSU 默认挂载表 → 需 post-fs-data.sh 自写 bind mount（会话层）。
2. 开机声 /system/media/audio/animationsounds/bootSound.ogg（唯一）；关机充电动画 /product_h/etc/media/charger/{1272x2800,public/1272_serial} png 序列；指纹解锁视频 /product_h/etc/settings/inside_screen_fingerprint_video.mp4。
3. 已应用主题落地 /data/themes/0/：fonts/icons/wallpaper/lockscreen(keyguard_clock_style.json)/unlock/aod/fingerprint_anim/com.android.systemui/com.hihonor.android.launcher。当前主题自带字体(DroidSansChinese.ttf)会遮蔽 KSU 系统字体模块——需先取消主题字体混搭。字体模块须同时换 /system/etc/font_fallback.xml（Android 17 字体真源，fonts.xml 已弃用）；HONORSansVF* 全是可变字体。
4. 内置开关（无需 root）：show_network_speed_enabled(网速,现关)、battery_percent_switch(已开)、statusbar_pure_mode(纯净模式)、themed_icon_enabled(彩色图标,现关)、aod_style=琉光 但 AOD 当前 close_aod。
5. /product_h/overlay/ 现役 5 个 RRO（SystemUIResOverlay/frameworkResOverlay 等）→ overlay 注入路线存在但实验性。
6. web：VoreulCH/HonorAdvancedSettings（药师，MagicOS11 专用：液态玻璃恢复三线+DIY14滑条+安装器净化；工程注记=只 hook 大方法防 AOT 内联/DexKit 字符串锚+参数签名扫描/配置走 ContentProvider；玻璃作用域含 com.hihonor.desktop.systemui，同装冲突）；zimu5683/honor-hwt-theme-studio（大雪 hwt 编辑器 0.2.5.4）。通用 KSU 开机动画模块全写死 /system/media 不认 /product_h → 荣耀侧空窗。

## Top5
1. ~~开机动画 KSU 模块~~ **降级为不可达（41 号质检+临时 root 推论）**：开机动画播放早于任何提权动作（一键越狱=开机后手动+概率性），KSU 模块的 post-fs-data/service 挂载链永远赶不上开机动画 → 本机永久不可行，除非工具支持开机自动提权
2. 液态玻璃并入 HonorHook（值5/M，抄药师点）【会话层，可行：hook 注入无需 boot 时序】
3. KSU 字体模块（值4/M，前置=取消主题字体，须动 font_fallback.xml）【会话层】
4. 状态栏电池/图标样式扩展（值4/M，复用 U7 Resources 三挂点轨）【会话层】
5. hwt 混搭一站式（大雪编辑器→指纹动画/锁屏时钟/AOD/图标，免 root 零风险，值4/S）
